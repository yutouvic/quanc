# Presages（奥秘小队）游戏规则与卡牌汇总

> 依据本次提供的清晰规则与卡牌图片整理。规则1、规则3提供了完整准备与轮次规则，规则2/4提供回合结算与细则提醒，卡牌1-35图片提供了点数、颜色、效果与结算时机。以下为汇总版。

***

## 一、游戏概述

**Presages（奥秘小队）** 是一款团队合作卡牌游戏，玩家分成两队，通过出牌、结算牌面效果争夺回合胜利；率先赢得 **2轮** 的小队获胜。

- 支持人数：4人、5人、6人
- 建议年龄：10岁以上
- 游戏时长：约30分钟
- 核心限制：**禁止任何形式的沟通**（不能讨论如何出牌，不能透露或交换手牌信息，除非牌面效果指定）

***

## 二、游戏配件

- **35张奥秘牌**：数值1–35，其中30–35为“绝对牌”。
- **7张玩家帮助牌**：用于标记队伍与轮次胜利，桂冠面朝下/朝上表示是否赢得一轮。

***

## 三、游戏准备

### 3.1 分队（绝对牌配对）

1. 从奥秘牌堆取出6张绝对牌（数值30–35），洗匀后面朝上发给每位玩家1张。
2. 4人或5人局：剩余绝对牌放回盒内，本局不用。
3. 按人数分队：

| 人数 | 分队方式                              |
| -- | --------------------------------- |
| 4人 | 绝对牌数值最高与最低的两位玩家为一队，其他2人为另一队       |
| 5人 | 绝对牌数值最高与最低的两位玩家为一队，其他3人为另一队       |
| 6人 | 依绝对牌数值配成3队，每队2人：30与35、31与34、32与33 |

### 3.2 帮助牌

- 每队拿取相同符号的玩家帮助牌，**桂冠朝下**放在各自面前。
- 当一队赢得一轮时，将该队玩家的帮助牌翻面（桂冠朝上），标记胜利。
- 5人局中，3人小队必须使用 ● 符号的帮助牌。
- **小队成员在整局游戏中不会更换。**

### 3.3 发牌

玩家将各自的绝对牌放入手中。将其他奥秘牌（数值1–29）洗匀，依人数面朝下发放：

| 人数 | 发牌方式                | 手牌总数（含绝对牌）    |
| -- | ------------------- | ------------- |
| 4人 | 每位玩家4张              | 共5张           |
| 5人 | 3人小队成员各4张；2人小队成员各3张 | 3人队5张 / 2人队4张 |
| 6人 | 每位玩家3张              | 共4张           |

剩余奥秘牌本局不使用，暂放一旁。

***

## 四、游戏流程

### 4.1 轮与回合

- 游戏包含**数轮**，每轮进行**数个回合**。
- 当一位玩家**只剩1张手牌**时，该轮结束，其所属小队赢得此轮。
- 当一个小队**赢得2轮**时，游戏结束，该队立即获胜。

### 4.2 回合进行

1. 玩家按**顺时针方向**轮流打出一张牌，放在自己面前。
2. 开局由**绝对牌数值最高**的玩家率先出牌；之后由**上一回合的获胜者**在下一回合率先出牌。
3. 打出有"闪电"符号的牌时，**立即结算该牌效果**，然后才轮到下一位玩家出牌。效果必须在下一位玩家出牌前结算完毕。
4. 当所有玩家都在自己面前打出一张牌时，该回合结束。

### 4.3 回合结束结算

1. **场上**指桌面中央的游戏区域，包含已打出在玩家面前的所有牌。
2. 有"沙漏"符号的牌**同时结算效果**。即使某效果要求弃掉另一张牌，被弃掉牌的效果仍会启动。
3. 判定胜利者：**场上数值最高的牌赢得该回合**，除非牌效果另有规定（如《镜子》《悲伤》）。
4. 胜利者将自己面前的牌弃掉。
5. 若效果允许弃掉场上某些牌，立即弃掉。所有因牌效果被弃掉的牌，会和获胜玩家打出的牌一起弃掉。
6. 如果您面前的牌未被弃掉，**收回手中**。
7. 每个回合至少会有1张牌被弃掉（即获胜玩家打出的牌），也可能多名玩家的牌同时被弃掉。

### 4.4 新回合与轮结束

- 若尚无任何小队赢得本轮（即回合结束时，至少一位队员仅剩1张手牌），则开始新回合，由上一回合胜利者率先出牌。
- 当一位玩家只剩1张手牌时，一轮结束，其所在小队赢得此轮。
- 若多位玩家在回合结束时都只剩1张手牌，则比较手牌，由**数值最高玩家的小队**赢得这一轮。
- 若因《运气》效果使您在回合结束时手牌变为0张，您的小队**立即赢得这一轮**，即使其他玩家在回合结束时只剩1张手牌。

### 4.5 新的一轮

- 若尚无任何小队赢得2轮，则开始新的一轮。
- 将所有奥秘牌重新洗牌，包含1–29号牌以及上一轮使用的所有绝对牌。小队成员不更换。
- 发牌数量：

| 人数 | 新一轮手牌数              |
| -- | ------------------- |
| 4人 | 每位玩家5张              |
| 5人 | 3人小队成员各5张；2人小队成员各4张 |
| 6人 | 每位玩家4张              |

- 上一轮为自己小队赢得该轮的玩家，在本轮第一回合率先出牌。
- 注意：由于上一轮使用的所有绝对牌都洗回牌库，可能出现有的玩家拿到多张绝对牌、有的玩家完全没有的情况。

## 五、细则提醒

- 玩家**必须执行**牌上的效果。
- 若无法执行牌上的效果，仍可打出该牌，只是效果不会发生。
- 打出**"闪电"符号**的牌时**立即结算效果**，效果必须在下一位玩家出牌前结算完。
- 回合结束时，场上**有"沙漏"符号的牌同时结算效果**。
- 「场上」是指桌面中央的游戏区域，包含已打出在玩家面前的所有纸牌。
- 禁止任何形式的沟通：不能讨论如何出牌，不能透露或交换任何关于手牌的信息（除非牌面效果指定您这么做）。
- 有**"沙漏"**符号的牌都会在回合结束时同时结算效果。即使某个效果要求您弃掉另一张牌，被弃掉牌的效果仍会启动。
- 所有因牌效果被弃掉的牌，会和获胜玩家打出的牌一起弃掉。
- 每个回合至少会有1张牌被弃掉（即该回合获胜玩家打出的牌），但也可能多名玩家的牌同时被弃掉。
- 若您面前的牌未被弃掉，收回手中。

## 七、关键卡牌交互说明

### 7.1 《镜子》与《悲伤》

- 《镜子》将回合胜利条件改为“数值最低的牌获胜”。
- 若《悲伤》与《镜子》同回合打出，可直接忽略《悲伤》的效果，因为不是数值最高或次高的牌都无法赢得该回合。
- 《悲伤》只忽略数值最高的牌的“数值”，其效果仍会启动。

### 7.2 《恐惧》的特殊性

- 《恐惧》不能被任何效果弃掉，除非它赢得该回合。
- 回合结束时《恐惧》回到手上。
- 《运气》的效果无法弃掉《恐惧》。

### 7.3 《律法》与《愤怒》《背叛》

- 打出《律法》后，若没有手牌符合其设定条件，如常打出所选牌。
- 若《律法》被《愤怒》收回，其所设定的条件在本回合后续游戏中不再适用。
- 若《律法》被《背叛》拿走，同样其条件在本回合后续游戏中不再适用。

### 7.4 《梦》的结算

- 打在自己面前：不启动效果。
- 打在其他尚未出牌的玩家面前：该玩家立刻打出一张牌放在您面前；若该牌有符号，立刻结算该效果。

### 7.5 《嫉妒》的结算

- 将此牌与场上任一张牌交换。
- 换到的牌若有符号，不能再次结算该效果（因为打出时已结算过）。

### 7.6 《运气》的即时胜利

- 若因《运气》效果在回合结束时手牌变为0张，您的小队立即赢得这一轮，优先级高于“其他玩家只剩1张手牌”的轮结束条件。
- 《运气》的效果无法弃掉《恐惧》。

### 7.7 《狡黠》（17）的多色属性

- 此牌属于所有颜色（绿、黄、红、蓝），在判定“场上是否有某颜色牌”“唯一某颜色牌”等条件时，它可被视为任意颜色。

## 八、回合结算示例（来自规则2）

场上有6张牌：18（白昼）、5（平静）、11（夏）、4（平静）、24（秘密）、8（死亡）。

结算结果：

- **《秘密》**：因数值最高赢得回合，同时因《白昼》效果“弃掉数值最高的红色牌”被弃掉。
- **《平静》**：场上有红色牌，且《死亡》效果会弃掉数值最低的绿色牌，双重原因被弃掉。
- **《夏》**：它是场上唯一的黄色牌，依本身效果被弃掉。
- 剩下的牌因没有效果弃掉它们，玩家各自将面前的牌拿回手中。

> 注：示例中《白昼》因《秘密》获胜而作为获胜牌被弃掉；《死亡》效果弃掉最低绿色牌（《平静》）；《夏》因唯一黄色牌被弃掉。

## 九、速查表

| 项目     | 规则                                      |
| ------ | --------------------------------------- |
| 胜利条件   | 先赢得2轮的小队获胜                              |
| 轮结束条件  | 一位玩家只剩1张手牌；多人同时只剩1张时，比较手牌数值，最高者小队获胜     |
| 回合胜利判定 | 数值最高的牌获胜（除非效果另有规定）                      |
| 出牌顺序   | 顺时针；首回合绝对牌数值最高者先出，之后上回合胜者先出             |
| 效果结算时机 | 打出时立即结算；回合结束时所有符号牌同时结算                  |
| 未弃掉的牌  | 收回手中                                    |
| 沟通     | 禁止任何形式沟通                                |
| 分队     | 4/5人：绝对牌最高与最低为一队；6人：30-35、31-34、32-33配对 |
| 手牌数    | 4人5张；5人3人队5张/2人队4张；6人4张                 |
